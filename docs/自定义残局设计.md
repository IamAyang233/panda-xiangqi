# 自定义残局 · 设计草案

状态：**待拍板**（§5 列出需确认的分歧点，§1-4 为已核对代码得出的方案）

背景：用户要「在残局里增加自定义残局，自己摆残局挑战」。上一版 grill-me 访谈结论随会话压缩丢失，未落盘；本版基于当前代码（HEAD `8dd4e7b`）重新推导，结论即时写入本文件。

## 1. 目标

大厅提供一个入口：用户摆好局面 → 设定执子方 / 先手 / 目标 / AI 档位 → 进入挑战。挑战过程与既有残局完全一致（守方引擎应着、可悔棋 / 提示 / 重开、目标判定同规则）。

## 2. 现有架构可复用点（逐条核对代码）

| 环节 | 现状 | 结论 |
|---|---|---|
| 残局数据 | `puzzle.Puzzle{FEN, PlayerSide, Goal, ParMoves, Solution}`（`puzzle.go:14`） | 自定义残局只需构造一个临时 Puzzle |
| 建局面 | `NewSession` 用 `ParseFEN(pz.FEN)`，失败回落满盘（`session.go:84`） | 自定义 FEN 直接可用 |
| 正解校验 | `solutionMoveAt` 在无 Solution 时返回 `""`；`ApplyPlayerMove` 只在 `want != ""` 时判偏离（`session.go:285`） | `Solution=nil` → 不触发偏离，任意合法着法都算正常 |
| 守方应着 | `aiReply` 中 `solUCI == ""` 落到 `default` → `engines.BestMove`（`session.go:420,442`） | 守方自动由引擎应着，无需新代码 |
| 目标判定 | `finishLocked`：`Goal=="draw"` 判和，否则判玩家将死 / 困毙（`session.go:361-368`） | 直接复用 |
| 重开 | `Restart()` 用 `pz.FEN` 恢复（`session.go:671`） | 重开回到用户摆的局面 |
| 提示 | `Hint()` 无正解时回落引擎建议（`session.go:614`） | 直接可用 |
| 异常兜底 | AI 出着非法 → 改走首个合法着法；无合法着法 → 正常判结束（`session.go:457-468`） | 非法局面不会卡死进程 |

**必须改的只有 3 处**：

1. `puzzleLevel()`（`session.go:505`）按 `pz.Difficulty` 映射引擎档位，自定义残局会落到 `default` 固定为 9 档 → 加分支：Difficulty 为空时用玩家选的 `s.Level`。
2. `finishLocked()` 星级（`session.go:377-385`）：`ParMoves=0` 时 `playerMoves <= 0` 恒假 → 落到 `else` 误给 2 星 → 加 `ParMoves > 0` 前置条件，自定义残局不评星。
3. `web/js/board.js` 只有 `parseFEN`（`board.js:13`），**缺 `boardToFEN`**（Map → FEN）——摆棋器提交时需要。

## 3. 后端改动

- `createGameReq` 加 `Fen string`（`api.go:124`）。
- `handleCreateGame` 的 `case session.ModePuzzle`：`req.Fen != ""` 时不查题库，改构造临时 Puzzle：

  ```go
  pz = &puzzle.Puzzle{
      ID: "custom", Name: "自摆残局", FEN: req.Fen,
      PlayerSide: req.Side, Goal: req.Goal,
      ParMoves: 0, Solution: nil, Difficulty: "",
  }
  ```

- **服务端必须校验 FEN**（否则前端可绕过校验把非法局面喂给引擎）。四条硬校验：
  1. `ParseFEN` 成功（已覆盖 10 行 / 字符合法 / 行长）
  2. 双方各恰好 1 个将 / 帅
  3. 将帅不照面
  4. 先走方至少有一个合法着法（`LegalMoves(Turn)` 非空）

  任一条不满足 → HTTP 400 并回具体原因。

## 6. 已知代价与风险

- 摆到一半刷新页面会丢（与「不持久化」决策一致；不做 sessionStorage 草稿）。
- 自定义残局没有正解，「提示」语义从「提示正解」变为「引擎建议的应着」。
- 服务端校验是唯一防线；若跳过，非法局面会让引擎返回错乱着法（实测不会崩进程，但语义无意义）。
